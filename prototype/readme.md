# JS Prototype
জাভাস্ক্রিপ্ট প্রোটোটাইপ হলো এমন একটা মেকানিজম যার মাধ্যমে একটি অবজেক্টের ফিচারসমূহ অন্য একটি অব্জেক্টে ইনহেরিট করা যায়. জাভাস্ক্রিপ্ট এর প্রতিটি অবজেক্টের মধ্যে  [[Prototype]] নামে  একটি হিডেন প্রপার্টি যার মধ্যে  এটি অন্য একটি অবজেক্টর রেফারেন্স থাকে।
এইভাবে রেফারেন্স অবজেক্টের [[Prototype]] এর মধ্যে ও অন্য একটি অবজেক্টের রেফারেন্স থাকতে পারে। এই পদ্ধতিকে Prototype Chain বলে.
যখন আমরা কোন একটি প্রপার্টি একসেস করার চেষ্টা করি তখন জাভাস্ক্রিপ্ট প্রথমে যেই অবজেক্ট থেকে কল করছে সেই অবজেক্টর মধ্যে খুজার চেষ্টা করে, যদি না পায় তখন প্রোটোটাইপের মধ্যে খুঁজে। তারপর যদি রেফারেন্স অবজেক্ট এর প্রোটোটাইপের মধ্যে ও না পায় তারপর সেই রেফারেন্স অবজেক্ট সেই অবজেক্ট কে রেফার করে সেই অবজেক্ট এ খুঁজে। এইভাবে যতক্ষন না পরর্যন্ত খুঁজে না পায় বা প্রোটোটাইপ চেইন শেষ না হয় ততক্ষন পরর্যন্ত খুঁজবে।

## `__proto__` vs `prototype`

### `__proto__`

এটি বাই ডিফল্ট সব অবজেক্টের মধ্যে থাকে। এটি মূলত প্রোটোটাইপ চেইন একটা অংশ.

### `prototype`
এটি কন্সটাক্টর  ফাংশন এর মধ্যে থাকে। এর মাধ্যমে আমরা কন্সট্রাক্টর ফাংশনের প্রোটোটাইপের মধ্যে প্রপার্টিজ বা মেথড এড করতে যেগুলো ওই কন্সট্রাক্টর ফাংশনের সব ইন্সট্যান্সের মধ্যে শেয়ার হবে যখনই নতুন ইন্সট্যান্স ক্রিয়েট হবে.
প্রোটোটাইপ আমরা ব্যবহার করি যাতে আমরা কিছু কমন মেথড বা প্রোপার্টি শেয়ার করতে পারি একাধিক অবজেক্টের মধ্যে। এটা ইনহেরিটেন্সের মতোই কাজ করে। ইনহেরিটেন্সের আরেকটি বড় উদ্দেশ্য হলো মেমোরি অপটিমাইজেশন।

### Used in Memory optimization
মেমোরি অপটিমাইজেশন আমাদের সহায্য করে মেথড শেয়ার করার ক্ষেত্রে। যখন একটি ফাংশন একবার লেখা হয়, তখন সেটি প্রোটোটাইপের মধ্যে সংরক্ষিত থাকে এবং প্রতিটি ইনস্ট্যান্স তা ব্যবহার করতে পারে, ফলে একই কোড বারবার লিখতে হয় না। যখন একটি ইনস্ট্যান্স থেকে মেথড কল করা হয়, জাভাস্ক্রিপ্ট প্রথমে সেটি ইনস্ট্যান্সের মধ্যে খোঁজে, না পেলে প্রোটোটাইপ চেইনে খোঁজে। এইভাবে, আমরা মেমোরি অপটিমাইজ করতে পারি, কেননা আমরা বারবার একই কোড লিখে মেমোরি নষ্ট করি না।

```javascript
// প্যারেন্ট কনস্ট্রাক্টর
function Animal(name, energy) {
    this.name = name;
    this.energy = energy;
}

// প্যারেন্ট প্রোটোটাইপে একটি মেথড যোগ করা
Animal.prototype.eat = function (amount) {
    this.energy += amount;
    console.log(`${this.name} is eating. Energy is now ${this.energy}`);
};

// চাইল্ড কনস্ট্রাক্টর
function Dog(name, energy, breed) {
    Animal.call(this, name, energy); // প্যারেন্ট কনস্ট্রাক্টরের প্রপার্টি ইনিশিয়ালাইজ করা
    this.breed = breed;
}

// চাইল্ড প্রোটোটাইপে প্যারেন্টের প্রোটোটাইপ সেট করা
Dog.prototype = Object.create(Animal.prototype);

// চাইল্ড প্রোটোটাইপে constructor ঠিক করা
Dog.prototype.constructor = Dog;

// চাইল্ড প্রোটোটাইপে একটি নতুন মেথড যোগ করা
Dog.prototype.bark = function () {
    console.log(`${this.name} is barking! Woof Woof!`);
};

// উদাহরণ ব্যবহার
const dog = new Dog("Buddy", 10, "Golden Retriever");
console.log(dog.name); // Buddy
console.log(dog.breed); // Golden Retriever

dog.eat(5); // Buddy is eating. Energy is now 15
dog.bark(); // Buddy is barking! Woof Woof!

console.log(dog instanceof Dog); // true
console.log(dog instanceof Animal); // true

```

ব্যাখ্যা:
* Animal কনস্ট্রাক্টর: এটি প্যারেন্ট কনস্ট্রাক্টর, যেখানে সাধারণ প্রপার্টি (name, energy) আছে।
* Animal.prototype.eat: প্যারেন্টের প্রোটোটাইপে eat মেথড যোগ করা হয়েছে, যা চাইল্ড অবজেক্টও ব্যবহার করতে পারে।
* Dog কনস্ট্রাক্টর: চাইল্ড কনস্ট্রাক্টর, যেখানে প্যারেন্টের প্রপার্টি ইনিশিয়ালাইজ করার জন্য Animal.call(this, ...) ব্যবহার করা হয়েছে।
* Object.create: চাইল্ডের প্রোটোটাইপে প্যারেন্টের প্রোটোটাইপ সেট করা হয়েছে, যাতে ইনহেরিট করা মেথড ব্যবহার করা যায়।
* Dog.prototype.bark: চাইল্ড প্রোটোটাইপে একটি নতুন মেথড যোগ করা হয়েছে যা প্যারেন্টে নেই।
এভাবে প্রোটোটাইপ ব্যবহার করে মেথড শেয়ার করে ইনহেরিটেন্স করা যায়।
## ES6 Classes and Prototypes
জাভাস্ক্রিপ্ট হলো একটি প্রোটোটাইপ বেইসড ল্যাঙ্গুয়েজ। জাভাস্ক্রিপ্ট এর ES6 ভারর্সন থেকে class সিনট্যাক্স এসেছে যার মাধ্যমে আমরা অন্যান্য ওওপি ল্যাংগুযেজ গুলোর মতো জাভাস্ক্রিট এ ও ক্লাস ডিফাইন করতে পারি। কিন্তু আন্ডার দি হুড জাভাস্ক্রিট স্টিল প্রোটোটাইপ ব্যবহার করে কাজ করে.
